
# 🍉 Fruit Ninja Game

A simple and entertaining Fruit Ninja-inspired game where players slice flying fruits to earn points while avoiding bombs. The game offers fast-paced gameplay, score tracking, and increasing difficulty for an exciting experience.

## 🎮 Features

- Slice fruits using mouse or touch controls
- Earn points for every successful slice
- Avoid bombs to stay in the game
- Score tracking system
- Smooth animations and effects
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Prerequisites

A modern web browser such as:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
